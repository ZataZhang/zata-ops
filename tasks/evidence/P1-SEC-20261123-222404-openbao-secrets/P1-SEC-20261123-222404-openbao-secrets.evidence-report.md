| 对应判据 | 观测 |
| --- | --- |
| rv-1 | CLI 在读权限会话中查到同一环境版本，应用和回滚预览可用。陈旧预期版本和普通身份的写请求都被拒。发布新版本后可按旧内容生成回滚版本。 |

| rv-3 | 旧 Raft 快照能恢复旧会话与旧值。隔离恢复后重新应用撤销和当前值，旧会话被拒，新会话读取当前值。生产签发方撤销、真实投递和宿主机灾备仍待试点。 |
