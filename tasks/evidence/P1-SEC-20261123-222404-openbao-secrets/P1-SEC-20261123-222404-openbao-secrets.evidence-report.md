| 对应判据 | 观测 |
| --- | --- |
| rv-1 | CLI 在读权限会话中查到同一环境版本，应用和回滚预览可用。陈旧预期版本和普通身份的写请求都被拒。发布新版本后可按旧内容生成回滚版本。 |
| rv-2 | 两条凭据分别读取，子进程拿到预期值，OpenBao 会话与宿主机无关变量未传入。缺第二条授权时子进程未启动。所有审计设备写入失败时请求失败。 |
| rv-2 | 归档目标缺失时进程报错。目标可用后补送，原始访问可按请求 ID 和对象版本读回。存储管理员提前永久删除和缩短留存均被拒。重建检查点后重放没有生成重复版本。 |
| rv-3 | 旧 Raft 快照能恢复旧会话与旧值。隔离恢复后重新应用撤销和当前值，旧会话被拒，新会话读取当前值。生产签发方撤销、真实投递和宿主机灾备仍待试点。 |
